# Assignment: Build Your Own MAS

Build a multi-agent system on the class demo — and make it solve a problem of your own.

## Hand in

- A recorded terminal run of your system (a screen video is fine).
- The code in a repo, with a README that says how to run it.
- A short note (2–4 pages): design, harness, what you measured.
- One real run’s artefacts: trace, report, review.

## Baseline — every project

- Two or more agents with different jobs, plus a review gate.
- A harness loop with a stop condition and a failure path.
- At least one real tool call whose result is used later.
- Evidence that can be checked: citations, logs, verdicts.

## Bonus points

- An interactive UI: timeline, messages, verdicts.
- Extend the demo: a new agent, tool or gate.
- Measure two designs on the same tasks (accuracy vs cost).
- One command that reproduces your results.

> **Bring your own problem — the demo is the starting line, not the target.**
